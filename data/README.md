# Dữ liệu

Dự án dùng bộ **VNTC** (tin tức tiếng Việt, 10 chuyên mục, 84.132 bài). Bộ dữ liệu quá lớn nên không đưa lên GitHub.

Cách lấy:
1. `python -m pip install underthesea`
2. `underthesea download-data VNTC`
3. Chép thư mục dữ liệu vừa tải vào `data/VNTC/` sao cho có hai file `data/VNTC/train.txt` và `data/VNTC/test.txt`.
